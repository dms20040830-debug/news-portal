# Проект «Новостной портал»

Учебное SPA-приложение для управления новостным контентом. Позволяет создавать, редактировать, публиковать и анализировать новости по различным категориям.

## Цель проекта
Создать удобный интерфейс для редакции новостного сайта: от написания черновика до публикации и сбора статистики просмотров.

## Технологии
- React
- TypeScript
- Vite
- CSS
- Моковые (тестовые) данные
